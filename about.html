台東食光｜探索台東在地美食

一、我做了什麼

本網站以台東在地美食為主題，使用 HTML 與 CSS 製作響應式網站。

網站介紹六種台東特色美食，包含米苔目、卑南包子、池上便當、成功漁港海鮮、原住民風味料理及關山米食。

另外加入圖片、文字介紹、導覽列與外部連結，讓使用者能認識台東美食。

二、我認為值得加分的特色

1. 響應式網頁設計（RWD）：依照電腦、平板及手機螢幕自動調整版面。

2. 美食圖片與卡片互動：滑鼠移動到卡片時會產生浮起效果。

3. 外部連結功能：點擊美食圖片或標題，可以前往相關美食搜尋結果。

4. 網站導覽功能：使用導覽列快速前往不同內容。

5. 獨立作業說明頁：另外建立頁面介紹網站製作內容與特色。

三、網站瀏覽注意事項

1. 建議使用 Chrome 或 Edge 瀏覽器。

2. 點擊美食圖片或標題，會在新分頁開啟相關搜尋結果。

3. 外部連結需要網路才能正常使用。

4. 本網站支援電腦、平板及手機瀏覽。

5. 若圖片無法顯示，請確認網頁資料夾中的 images 圖片是否完整。
